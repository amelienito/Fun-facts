# Fun facts

OSB Corporation présente : un terrier de faits vérifiés. Chaque réponse ouvre deux pistes ; celle qu'on ne suit pas est gardée.

- `index.html` + `jeu.css` + `js/jeu.js` : la V4 (le jeu).
- `js/questions.js` : les questions, les séries, les pépites et les niveaux.
- `js/data.js` + `js/notes.js` : les faits, leurs sources et la frise.
- `js/objets.js` + `js/scene.js` : les objets 3D low poly.
- `cabinet.html` : l'ancienne version (cabinet de curiosités).
- `maquettes/` : les 3 maquettes de style (terrier, lampe, toile).
- `notes-triees.md` : l'état de chaque note.

Polices sous licence OFL (`fonts/`). 3D : three.js r186, licence MIT (`vendor/`).
