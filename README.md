# Fun facts

OSB Corporation présente : un cabinet de curiosités à remplir de faits vérifiés.

- `js/data.js` : tout le contenu (salles, questions, sources, frise).
- `js/objets.js` : les objets 3D low poly, un par salle.
- `js/app.js` : le parcours (tiroirs, salles, portes, archives, cabinet).
- `notes-triees.md` : les notes en attente de tri.

Polices Gravitas One et Literata (licence OFL, dans `fonts/`). 3D : three.js r186 (licence MIT, dans `vendor/`).
